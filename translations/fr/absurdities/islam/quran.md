# Extraordinary claims

- An-Naml (27:18-19) - Rapporte qu’une fourmi avertit les autres de l’armée de Salomon et que celui-ci comprend ses paroles. | Explanation: Les fourmis communiquent entre elles, mais l’élément extraordinaire est que Salomon comprend l’avertissement précis d’une fourmi au sujet de son armée. Le récit présente cette faculté comme exceptionnelle, non comme une capacité humaine ordinaire.
- Al-Qamar (54:1-2) - Décrit la lune se fendant ; généralement interprété comme un miracle, mais certaines lectures l’associent à l’avenir. | Explanation: Le texte décrit la lune se fendant. Une division physique littérale de la Lune constituerait un événement astronomique extraordinaire ; de nombreuses interprétations y voient un miracle, tandis que d’autres y voient un signe futur.
# Scientific tensions

- Al-Kahf (18:86) - Décrit le soleil se couchant dans une source du point de vue d’un voyageur ; une lecture astronomique littérale contredit la science. | Explanation: Le voyageur voit le soleil comme s’il se couchait dans une source. Une lecture physique littérale contredit l’astronomie, tandis qu’une description de sa position apparente depuis ce point de vue n’implique pas que le soleil entre dans la source.
